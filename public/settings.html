Display Behavior

Drops unneeded units as the timer counts down: the hours are hidden once less than an hour remains, and the minutes once less than a minute remains.

End counter

While a draw is running, shows the current end (END 2, END 3…) in place of "Time remaining:". Each draw needs a time per end before anything appears, and the number is hidden again at the running warning threshold.

Applies one time per end to every draw and local timer, ignoring the value stored on each draw. Turning this off restores the per-draw values.

Required while the override above is on. Whole minutes between 1 and 120.

min

Each new end starts with the number enlarged to draw attention, then it returns to its normal size. This is how much of the end it stays enlarged: 50 is the first half, 0 never enlarges it.

%

How much bigger the end number is while enlarged, relative to the status size (1.5 = 150%).

×

The countdown shrinks to make room for the bigger end number. 100% leaves it unchanged, which can push the top of the display off the screen if the end number is very large.
